# Code of Conduct

This project is a place to build and discuss the NOWPayments SDKs. People interacting in issues, pull requests, and discussions are expected to:

- Be respectful and assume good intent.
- Keep feedback about the code, not the person.
- Stay on topic. Support questions belong in an issue; security reports belong in [SECURITY.md](./SECURITY.md).
- Accept that maintainers may decline a change that does not fit the project.

Harassment, personal attacks, and discriminatory language are not welcome. Maintainers may edit or close comments and issues that break these expectations, and may block repeat offenders.

Report conduct problems by opening a GitHub security advisory on this repository and marking it as a private report, or by contacting the maintainer through their GitHub profile: [Foisalislambd](https://github.com/Foisalislambd).
